# Between Practice — static website preview

Responsive, build-free HTML/CSS/JavaScript for an independent production practice.

## Content

Work contains ten source-backed projects: ANDY, Time Smuggler, A.PHANTASIA, PHANTASMAGORIA, (Embodied) tools for decentralization, CCC, LNX, Non-Ego, POOLBOY and Mii&Ocean. Each has a detail page with supplied context, credits and documentation. 82 optimized JPEGs are included. Original documents and full videos remain in the local source library; video playback is not yet connected.

Program titles and activity labels remain generic placeholders at the user’s request. Services, Research, About, Contact and future Shop retain the preview architecture. Studio name and incomplete information remain clearly provisional. Missing photo credits, dates and roles need completion; conflicting source dates are flagged.

## Editing

Edit the standalone HTML pages. Shared styles and interactions live in assets/site.css and assets/site.js. project-content.json records the project content. Update repeated headers and footers across pages when changing navigation. Images are in assets/.

## GitHub Pages

Upload this folder’s contents to the repository root, including assets/ and .nojekyll. Commit to main. In Settings → Pages select Deploy from a branch, main, /(root), and save. Existing Pages deployments update on commit. No framework or build step is needed.

Local preview: python3 -m http.server 4174, then open http://localhost:4174.

## Preview limitations

Contact and newsletter forms demonstrate interaction but do not send or store submissions. No payment collection is connected. Unlisted pages and noindex do not provide authentication; protected writing requires real access control.
